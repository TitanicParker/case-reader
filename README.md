# Case Reader

A restrained, public-record style site examining the administrative foreclosure of a diagnostic sequence.

## Project purpose

This repository contains a static, accessible, federal-style public information site. It presents a structured reading of a July 2017 neurology admission, discharge record, Long Term Illness certification, DAT scan addendum, and downstream governance handling.

The site is organized around a sequence-based rule:

> Finality must follow inquiry, not precede it.

## Design direction

The visual system uses a restrained U.S. civic/government style: clear hierarchy, high contrast, limited color, formal typography, accessible navigation, and evidence-first page structure. The site does not impersonate a real government agency.

## Files

- `index.html` — single-page public site with the full case structure.
- `styles.css` — federal-style visual system and responsive layout.

## Editorial note

The text is framed as a documentary examination, not as a medical instruction page or a final adjudication of clinical liability. It keeps the focus on sequence, record integrity, administrative reliance, and the distinction between reasonable suspicion and premature finality.
